# Skill Swap

Skill Swap is a web-based platform that allows users to teach and learn skills from each other. Users can create profiles, add the skills they can teach and the skills they want to learn, and connect with other users for skill exchange.

## Features

- User Registration and Login
- User Profile Management
- Add Skills to Teach and Learn
- Find Users Based on Skills
- Send and Manage Skill Swap Requests
- Accept or Reject Swap Requests
- Schedule Skill Exchange Meetings
- Tutor Registration and Management
- Tutor-Created Mock Tests
- Users Can Attempt Mock Tests
- Automatic Mock Test Score Calculation
- Certificate Request After Passing
- Online Payment for Certificates
- Certificate Generation and Issuing
- Admin Management

## Technologies Used

- HTML
- CSS
- Bootstrap
- Django
- PostgreSQL
- JavaScript

## Project Description

The main goal of Skill Swap is to create a platform where people can exchange knowledge and improve their skills. Users can teach skills they already know while learning new skills from others. Tutors can also create mock tests to evaluate learners. After successfully completing the required course and passing the mock test, users can request a certificate through the payment and certification system.
